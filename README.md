# 余晖 Afterglow

面向风光摄影的晚霞规划网页，使用真实天气预报和可解释的实验性规则评分。

## 使用

GitHub Pages 静态部署，不需要 Python 后端或 API 密钥。直接打开发布后的 HTTPS 页面即可使用地址搜索、浏览器当前位置、日期与坐标输入、可选机位朝向、云图/卫星窗口、日落方位图、浅色/深色/自动外观和浏览器本地保存机位。GPS需浏览器授权，定位方式及精度由设备决定。

本地调试：Python 3.10+，运行 `python server.py`，打开 http://127.0.0.1:8765 。本地 MET Norway 通过同源适配转发；公开 Pages 使用官方 API 的浏览器访问。静态页面核心计算在 `web/engine.js`。

## 多源综合

默认权重：Open-Meteo / NOAA GFS 40，Open-Meteo / DWD ICON 35，MET Norway Locationforecast 25。可修改并保存到当前浏览器，设为0停用。权重是工程起点，未经历史观测准确率校准。

每一路独立获取拍摄点及日落方向 ±30°、30 / 80公里六点预报，独立评分，再按设置权重平均各来源总分。失败来源不参与，剩余权重归一。显示来源得分、实际权重和极差；全部失败就报错，不返回示例数据。字段缺失单独归一，降水折减单独应用，因此显示的分项不能直接线性还原综合总分。云量图表是加权平均条件，不代表一个独立天气情景。

MET Norway 是区域/全球混合预报产品，不能等同于单一天气模型，全球区域可能使用 ECMWF。多平台也不等于独立证据。可靠性最高仅标“中”，考虑来源覆盖、完整性、空间采样、时效和评分分歧，不是概率或置信区间。

## 数据与边界

- Open-Meteo 提供分层云、能见度等；MET Norway 缺能见度不补假值。浏览器短时内存缓存，不记录历史预报或上传机位。
- 地址搜索：Photon / OpenStreetMap，失败或无结果后尝试 Open-Meteo / GeoNames；结果需用户确认，不保证门牌级精度。
- 云图使用 Windy 官方 Embed，不调用随机扰动的 Point Forecast Testing API。图内时间/模型不与评分表单自动同步，地图可独立切换。
- 日落采用 NOAA 分数年近似与−0.833°阈值，蓝调−4°至−6°，不计地形与实际折射变化。精密规划与高纬度需复核。
- 评分：受光35%、方向低云代理25%、结构代理20%、能见度10%、稳定性10%，降水另作折减；尚无地形遮挡、云光学厚度和历史校准。
- 潜力指数不是发生概率或色彩强度。拍摄窗口是日落前30分钟至后20分钟的经验窗口，不是已优化最佳时间。
- GPS坐标用于所选天气服务和地图查询；地址关键词发送到地址服务。机位与主题、权重仅保存在用户自己的浏览器。
- 开放服务受可用性、跨域、地区网络和用量政策影响；接口失败时明确降级，不能保证所有网络环境实时可用。正式商业使用需核对授权。详见 [DATA_SOURCES.md](DATA_SOURCES.md)。

## 检查与部署

`node --test tests/engine.test.cjs` 验证静态引擎，`python -m unittest discover -s tests -v` 验证保留的 Python 原型。前端语法使用 `node --check web/app.js`。

推送到 main 后，GitHub Actions 运行引擎测试，将 `web/` 部署到 GitHub Pages。工作流：`.github/workflows/pages.yml`。

## 整合方向

现有光线规划器位于 https://xljfz.github.io/tools/light-planner/ ，其源码属于 XLJFZ.github.io 仓库。已核对它使用 MapLibre、SunCalc、相机/主体坐标、太阳月亮方位、焦段与视角计算、导出卡片。建议将本项目 engine.js 的天气适配与综合评分作为独立模块接入该工具，共用地点、日期、时区与相机至主体方位。当前未修改原网站，也未宣称已完成跨站参数同步。

## 火烧云观赏潜力（rules-0.3）

与原有晚霞潜力分开评分，不能解释为发生概率、真实饱和度或摄影审美结论。

每一路预报独立计算：中高云画布40%、分层共存20%、方向低云开口25%、云量稳定性15%，然后使用同一组来源权重汇总各路观赏得分。画布以高/中云量的较大值作为保守代理，不能推断两层云的真实重叠；高/中云共存只能提示层次可能，不能识别卷云、鱼鳞云或实际纹理。无中高云时通过画布门限使火烧云观赏分为0，覆盖过满则降分；方向低云和降水另作折减。

这些阈值和权重都是工程启发式，需要真实照片与观测校准。当前缺少云光学厚度、云形、气溶胶、实际受光几何与色彩观测。物理背景参考 NOAA 的云色解释：https://www.noaa.gov/jetstream/clouds/color-of-clouds 和 NWS 的日落色彩说明：https://origin-west-www-spc.woc.noaa.gov/publications/corfidi/sunset.html 。资料支持云高、厚度和光路的重要性，不为本项目阈值背书。

## 区域朝霞与晚霞图（rules-0.4）

在“区域预测图”生成：选择周边/中国粗略概览/当前视野，朝霞或晚霞，以及单个GFS/ICON模型。63格每格独立计算当地事件时刻，441个位置预报分批查询。支持点击网格选机位、切换观赏与条件指标、取消、SVG及JSON导出。无数据保持缺失，分数不是概率，放大不会增加预报分辨率。单模型区域图与上方多源点位评分须区分。

参考与限制详见 [算法调研](ALGORITHM_RESEARCH.md)。Leaflet 1.9.4 来自官方文档指定的 unpkg 发行版，许可保留在 vendor 文件头；底图标注 OpenStreetMap。全国精细预测仍需要后端网格计算，当前未接入 CAMS 气溶胶或三维云场。
